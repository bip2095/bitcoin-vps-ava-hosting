## 按用途选档：哪些跑得动，哪些跑不动

比特币相关的工作负载对配置的要求差别极大，按磁盘和内存两条线判断最准。

**修剪节点（pruned node）** 验证全部规则，只保留最近的一部分区块，行业通行口径是约 20GB 磁盘。Ava Hosting 的 VPS One 给 25GB，理论上刚够，但没有余量给系统更新和日志；Basic 的 40GB 更稳。内存方面 2GB 能跑，4GB 更从容。

**完整归档节点（full archival node）** 需要存整条链，行业口径约 700GB，加上增长空间建议留到 800GB 以上。Ava Hosting 当前最大的套餐是 120GB。这一项直接排除：要在这家跑完整节点，磁盘不够，没有折中方案。

**BTCPay Server** 自带一个完整节点后端，磁盘需求和上面的归档节点同量级，同样超出 Ava Hosting 的套餐上限。想自建收款又必须用这家的，只能外接节点。

**闪电网络节点** 只存通道状态，磁盘需求小，真正的门槛是长期在线和稳定 IP。VPS One 这一档就够，重点选月付而不是年付，先跑一个月看稳定性。

**交易机器人** 吃内存和网络延迟，不吃磁盘。跑一两个策略，VPS One 或 Basic 足够；同时跑多个交易所连接、需要固定 IP 加入白名单的，Basic 起步更稳。

**私人 VPN / 代理** Nano 或 One 都行，Nano 的 100Mbps 带宽是唯一限制，做个人 WireGuard 出口够用，多人共享会顶到带宽上限。

几个结构性差异比"匿名"更影响实际使用：

**计费单位不同，起价没法直接比。** Ava Hosting、WolfVPS、Skhron 按月，NoctHost 和 bithost 按小时。按小时的好处是删机即停止计费，适合短期项目和频繁重建；按月的好处是价格可预期，年付还有折扣。

**IPv4 是不是包含在套餐里。** Ava Hosting 官方写明所有套餐含独立 IPv4。Skhron 的 IPv4 不含在套餐内，要按 €0.65/月/个单独加购，只有 IPv6 的机器通过 NAT64 访问 IPv4 服务，纯 IPv4 网络无法主动连进来。低价档的"起价"里有没有独立 IPv4，是选之前必须确认的一项。

**要不要邮箱，各家做法不一样。** WolfVPS 用账户 token 登录，不需要邮箱；NoctHost 和 bithost 都要邮箱。公开测评提到 Ava Hosting 可以用假名注册，但注册环节本身仍需提供一个可用的联系方式。把"这类服务都不用邮箱"当成通例，会在注册第一步卡住。

**比特币是假名，不是匿名。** 每笔链上交易都留在公开账本上，可被追踪分析。把服务器和真实身份隔开的，是商家不收集证件、不要求信用卡，而不是比特币本身的隐蔽性。要真正不可关联的支付，得用门罗币这类隐私币，Ava Hosting 的 20 多种币种里是否包含门罗币，需要在结账页确认。
